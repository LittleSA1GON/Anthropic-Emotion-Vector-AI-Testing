## E. Dataset design and metric caveats

Corpus has 12 unique scenarios, each reused across the same four emotion types but assigned to only one split, preventing scenario leakage: 6 train / 3 validation / 3 test per emotion. 4 emotions: `joy`, `calm`, `anger`, `anxiety`. Each JSONL row holds `id`, `scenario_id`, `emotion`, `split`, `neutral_prompt`, `emotion_prompt`, `source`, `annotation_note`. The dataset SHA256 is stored in run manifest. Corpus and feeling descriptions are authored synthetic language; lexical features (e.g. 'angry') are **not controlled** and can confound results. Do NOT claim emotion concept isolation.

**Captures:** for each text, run one prefill-only model forward pass and save decoder BLOCK output for the last prompt token. Output `positive` and `neutral` float32 arrays of `[N,L,H]`. MIA config specifies 1-based layer capture indices; the suite uses 0-based physical decoder block indexes throughout. Both methods might differ in chat formatting or hook location; parity must be explicitly checked. No output-sample labels are inferred from activation sign.

**Fitting:** train-only mean difference `v_l = mean(h_emotion - h_neutral)` normalized by L2 per layer. This is a candidate functional direction, not a proven psychological concept. **Selection:** use held-out validation pair margins `dot(h_emotion-h_neutral, v_l)` to choose the layer with highest fraction positive, breaking ties by highest mean margin; this is frozen before test. **Holdout:** test positive fraction, mean margin, median, standard deviation, by layer and chosen layer. All figures are descriptively exploratory; only 3 held-out scenarios per emotion. **Cross precision:** cosine similarity between matched FP16 and NF4 vectors, layerwise. `.compare` refuses model-ID/dataset/layer mismatches. Cosine doesn't establish steering causality. **Intervention:** add `alpha*v` to the last token state at chosen decoder block during prefill/decode, compare deterministic generations with `alpha=0,3,6`. Different backends/quantization may have different effective coefficient scaling; run dose-response sweeps; judge blindly.

**Further controls before publish:** paraphrase heldouts, shuffled emotion labels, random vectors with matched norm, opposing-direction steering, purely stylistic adjective controls, neutral factual reasoning tasks, semantic semantic similarity of matched pairs, blind multi-annotator ratings, confidence intervals with scenario-level bootstrap, multiple independent runs, balanced prompt lengths, manual tokenization parity tests, safety and utility checks.

# DATASET DATASHEET — emotion_pairs_v1.jsonl

**Dataset type:** fully synthetic human-authored structured paired prompts (generated deterministically from a short template). **Size:** 48 paired observations = 96 prompts across 12 distinct scenario topics, 4 emotion conditions and 3 disjoint splits. **License:** the suite's own templates; no external personal or private records. **Purpose:** smoke/pilot research on activation contrasts, NOT a benchmark for inferring internal feelings, psychology, or real-world affect.

## Composition

Each row: `id` unique pair; `scenario_id` groups related prompts; `split` (`train`, `validation`, `test`); `emotion` (`joy`, `calm`, `anger`, `anxiety`); `neutral_prompt` and `emotion_prompt` holding a fixed scenario but differing by a short first-person emotion framing; `source=author_created_synthetic_v1`; `annotation_note` guidance (not training label). Scenarios assigned 6 train, 3 validation, 3 test, shared consistently across all four emotions. There are thus 24/12/12 paired rows across splits.

## Known weaknesses

- Directly names affective states in positive prompts, so vectors can reflect lexical words rather than a latent affective function.
- Synthetic first-person prompts can reflect style instruction/assistant formatting; not necessarily a general emotion mechanism.
- Only 3 held-out scenarios per emotion; descriptive metrics cannot establish stable generalization.
- No blinded label annotation or natural conversational examples. The data must not be called benchmark-standard or psychologically validated.
- Some neutral prompts are repeated across emotions for the same scenario by design; the splitting guarantee is by `scenario_id`, not row. This is appropriate for controlled contrasts but can induce common neutral direction biases.

## Auditing and versioning
